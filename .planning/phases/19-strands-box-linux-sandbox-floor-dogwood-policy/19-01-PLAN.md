<threat_model>
## Security & Sandbox Boundary Threats (ASVS L1)

| ID | Threat | Mitigation Across Phase 19 Plans |
| :--- | :--- | :--- |
| `T-19-01` | In-session compromised `write`/`edit`/`python_repl` mutating `box.toml` or `policy.dw` to weaken next-launch containment | Default storage under host-only `~/.config/strands-box/repos/<slug>-<hash8>/` excluded from `[agent.filesystem].write`; `policy/core.py` downgrades broad `[[allow]]` globs targeting `~/.config/strands-box/**` to `Prompt` (`19-02-T1`); `--out` inside writable paths warns prominently |
| `T-19-02` | Symlink race/clobber on `~/.config/strands-box/.../{box.toml,policy.dw}` or `--out` config directory | `_refuse_symlink()` checks both target and parents before reading/writing/running; atomic `tempfile.mkstemp` + `os.chmod(0o600)` + `os.replace()` under `0o700` dirs |
| `T-19-03` | Opening `sts.amazonaws.com` egress or forwarding provider keys on wrong headers/hosts (`live_pricing.py` phantom block, GitHub redirect token leak) | Zero `sts.amazonaws.com` hole for `bedrock`; exact headers (`x-goog-api-key` Google, `x-api-key` Anthropic, `Bearer` OpenAI/Meta/TypeSafe); path-scoped `openrouter` (`/api/v1/chat/*`, `/api/alpha/decisions`); `GITHUB_TOKEN`/`GH_TOKEN` restricted strictly to `api.github.com` (never `codeload`/`objects`) |
| `T-19-04` | Secret value leakage into generated `box.toml`, doctor output, error strings, or logs | Emit symbolic `env://VAR` / `aws://[profile]` references only; check non-empty env presence without printing values; canary-verified across all 7+2 providers |
| `T-19-05` | TOML / Cedar-Dogwood injection via control chars (`\n`, `\r`, `\x00`) or quotes in repo path, `--region`, `--aws-profile`, or env strings | Reject ASCII control chars (`ord < 32`, `127`) in config string inputs (`ValueError`), validate `aws_profile`/`region`/`provider` strictly, and serialize TOML/Dogwood strings with proper quoting (`json.dumps`) |
| `T-19-06` | `codeact_shell` (`CodeactStint`) bypassing Strands Shell `sh` alias and Dogwood `shell:spawn` temporal log under `STRANDS_BOX=1` | `19-02-T1`: route `codeact_shell` through `["sh", "-c", shlex.join(argv)]` when `is_in_strands_box()` is True while preserving `isinstance(argv, str)` refusal and shell-metacharacter quoting |
| `T-19-07` | Silent Ubuntu 24.04 AppArmor `userns` `EPERM`, missing co-located Linux 3-binary layout, or missing `EXPERIMENTAL_X86_SUPPORT=TRUE` on Linux `x86_64` | `discover_box_binaries()` requires co-located `box`, `strands-box-contain-trampoline`, `strands-box-sock-alias`; `run_box_doctor()` checks AppArmor sysctl/profile & `x86_64` flag; `launch_box_run()` injects `EXPERIMENTAL_X86_SUPPORT=TRUE` on `x86_64` |
| `T-19-08` | Shell/env bleed from host or `strands_code_cli.entry.main` import cycle or `test_no_credential_persistence_sinks` violation | `tests/conftest.py` scrubs `STRANDS_BOX_BIN` + `EXPERIMENTAL_X86_SUPPORT`; keep all `os.environ` inside `sandbox/box.py` (`first_run.py` / `codeact.py`); zero `entry.main` imports in `sandbox/` |
</threat_model>
