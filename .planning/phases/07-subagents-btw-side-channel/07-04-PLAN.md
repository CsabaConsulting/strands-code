## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| turn-pump→session-pump | Nested pump exits must preserve the outer pump's entered state; a lost entered state reroutes worker prompts to the inline path where asyncio nesting fails |
| parent-history→btw-fork | The forked prompt carries an unanswered main directive; without scope marking the side agent performs main-task work under the btw identity |
| pump→dead-worker-requests | Cancelled workers leave queued or in-dequeue requests; the pump must skip dead-tag requests instead of serving phantom dialogs |
| sdk-exception→cancel-ux | The SDK wraps TurnCancelled in EventLoopException; the mapping must unwrap it or internal exception text leaks into the transcript |
| approval-dialog→user | Multi-dialog flows without per-box attribution let the user approve the wrong agent's request |
