## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| idle-prompt→broker-queue | The multiplexed idle prompt (or fallback announce/serve) observes the broker queue; a missed poll re-hides approvals, a double-serve breaks at-most-once service |
| serve-site→terminal | Suspend/serve/re-issue (or empty-Enter serve) owns the terminal sequentially; a nested app or unrestored state wedges or tears the UI |
| exit-path→transcript | The exit drain cancels a live side run; without a note the drop is silent, with a stale promise it is misleading |
| stdin→dialog-vs-reader | Mid-turn dialogs and the steering reader share fd 0; concurrent reads steal key bytes and turn mashed retries into phantom confirms |
