## Security & Reliability Threats (ASVS L1)

| ID | Threat | Mitigation in Plan 17-01 |
| :--- | :--- | :--- |
| `T-17-01` | Ambient host `TYPESAFE_API_KEY` / `JEV_API_KEY` leaking into offline tests or `routing.yaml` | Add both to `tests/conftest.py:_PROVIDER_ENV_VARS`; keep reads in `routing/core.py` & `routing/transports.py` header-only (verify `test_no_credential_persistence_sinks` stays green) |
| `T-17-02` | Secret echo in HTTP error messages, OTel span exceptions, or hold details | `failure_reason()` returns short error classes only (`HTTP 401`, `timeout`, `refused`, `unreachable`, `invalid body`), never response bodies or request headers |
| `T-17-03` | Ollama `OLLAMA_API_KEY` leaking onto loopback HTTP URLs or non-`http(s)` SSRF | Enforce `valid_base_url()` (`http`/`https` + hostname) and `_ollama_headers()` suppressing `Authorization` on loopback (`localhost`, `127.0.0.1`, `::1`) |
| `T-17-04` | Closed-event-loop `httpx.AsyncClient` crash or hangs on pre-turn / `/btw` threads | `run_decision_sync()` branches on active event loop (direct `asyncio.run` vs dedicated worker thread) with per-call `async with make_async_client(timeout)` |
| `T-17-05` | Truthy `Uncertain` sentinel treated as a candidate string or fell back to `candidates[0]` | Explicit `isinstance(val, Uncertain)` check in `decision_result_to_engine_result()`, short-circuiting to held `EngineResult(answers=None, uncertain=True)` |
</threat_model>
