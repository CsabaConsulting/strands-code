| auto-title prompt→model | First-exchange content is sent to the model for titling |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | router.py `/rename` value | high | mitigate | Validate rename (reject path separators and empty strings, cap length); store titles only in the sidecar JSON, never as filenames or blob keys. BLOCKING until the negative test passes. |
| T-02-02 | Tampering | picker index join | medium | mitigate | Treat the sidecar index as untrusted: fail-soft on corrupt JSON, ignore entries with no matching snapshot. |
| T-02-03 | Information disclosure | auto-title prompt | low | accept | Title call sends only the first exchange the user already typed; no additional context is attached. |
</threat_model>
