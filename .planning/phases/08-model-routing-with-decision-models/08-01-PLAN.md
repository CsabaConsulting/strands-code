## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repo strategy file to loader | Operator-editable YAML crosses into routing; entries are untrusted input |
| CLI to OpenRouter decisions endpoint | Truncated ask plus directives leave the machine; key travels header-only |
| CLI to local Ollama daemon | Same payload stays on loopback; no key material on loopback |
| Hook to switch machinery | Routed model id plus level applied pre-turn at idle |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-21 | Tampering | validate_choice_answer | high | mitigate | Type, probability range/sum, and live-candidate membership checks; stale or malformed tables hold, never route |
| T-08-22 | Information disclosure | decide_via_openrouter | high | mitigate | Key read at call time inside the engine function only, header-only, constant endpoint URL, never logged; save drops secret-shaped keys |
| T-08-23 | Tampering | build_decision_state | medium | mitigate | Ask plus directives each truncated to ASK_TRUNCATE_CHARS; candidate stats stay code-side, never enter the call |
| T-08-24 | Denial of service | decide_via_openrouter | low | mitigate | DECISION_TIMEOUT_SECONDS plus at most one retry on retryable codes only; every failure holds and the turn proceeds |
