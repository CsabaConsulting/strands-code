# Plan 19.1-02: Direct `PolicyGateHandler(InterventionHandler)` Migration, Per-Agent State & Thread-Safe HITL Rendering

<objective>
Replace the `HumanInTheLoop` wrapper + `DENY:` smuggling + thread-local `_ASK_TAG` + `SteeringState.arm` + `_ACTIVE` global with a direct, thread-safe `PolicyGateHandler(InterventionHandler)` keyed by `id(agent)` with `read_only_agents` support and main-thread HITL prompt rendering (`D-01`, `D-03`, `D-04`, `D-05`, `D-07`).

Purpose: Eliminate structural indirection, `allowed_tools` bypasses, `trust_delegated` `[[deny]]`/sensitive skips, `btw`/`subagent` tag collisions, 200-char `BatchState` collisions, and worker-thread `output_context()` races, then update & expand the full policy/steering/loop test suite in sync.
</objective>

## Security & Concurrency Threats (ASVS L1)

| ID | Threat | Mitigation in Plan 19.1-02 |
| :--- | :--- | :--- |
| `T-19.1-07` | `HumanInTheLoop(allowed_tools=["read", "search"])` short-circuiting `[[deny]]` rules and sensitive reads, plus stale `HumanInTheLoop` split-brain `_last_by_tag` / `ToolUseId` cache races | `PolicyGateHandler` runs single-step `before_tool_call` on EVERY tool call (no `allowed_tools` exemption, no `_last_by_tag` / `_ASK_TAG` / `ToolUseId` split) |
| `T-19.1-08` | `BatchState` 200-char prefix collision hiding differing trailing payloads (`write` / `shell` / `python_repl`), unlocked concurrent `set`/`list` mutation, and `trust_delegated` skipping `[[deny]]` or protected/sensitive paths | `BatchState` protected by `threading.Lock` and keyed on full canonical SHA-256 JSON digest; `decide()` runs BEFORE `trust_delegated` check and `not _is_protected_prompt(...)` blocks auto-trust on secret reads / protected writes |
| `T-19.1-09` | Worker-thread `output_context()` mutating `sys.stdout`/`sys.stderr` concurrently across SDK/btw threads & unlocked `steering.py` terminal prints interleaving escape sequences | Render interactive HITL prompt headers, Syntax diffs, and typed/dialog input INSIDE `ApprovalBroker.request(...)` callable on main pump thread; wrap non-interactive gate/steering prints with `with RENDER_LOCK: print_plain(console, ...)` |
| `T-19.1-10` | `SteeringState.arm` coupling/races or `on_error="deny"` swallowing `TurnCancelled` on Ctrl-C | `PolicyGateHandler` checks `event.cancel_tool` directly (`SDK_FIRST` hook runs before `INTERVENTION_INPUT`); keeps default `on_error="throw"` and re-raises `TurnCancelled` / `KeyboardInterrupt` |
</threat_model>
