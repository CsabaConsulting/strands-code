## 1. Shared Persistence Leaf (`strands_code_cli/platform_io.py`)

Pure stdlib leaf (`os`, `re`, `tempfile`, `pathlib.Path`); **zero imports from `strands_code_cli.*`**.

- **Thread-safe readable repo file mode (`mode=None`):**
  ```python
  def _read_process_umask() -> int:
      try:
          for line in Path("/proc/self/status").read_text(encoding="utf-8").splitlines():
              if line.startswith("Umask:"):
                  return int(line.split(":", 1)[1].strip(), 8)
      except (OSError, ValueError):
          pass
      return 0o022
  ```
  - Never calls `os.umask(0); os.umask(old)` (process-global race under worker threads!).
  - When `mode is not None` (default `0o600` for private config/cache/box/session/`.agent/` files): `os.chmod(tmp_path, mode)`.
  - When `mode is None` (git-tracked `./STRANDS.md`, `./.agent/skills-lock.json`): `os.chmod(tmp_path, 0o666 & ~_read_process_umask())` (yields `0o644` under standard `0o022` umask, matching `Path.write_text` + preserving `tests/memory/test_memory_file.py:120-126`).
- **Symlink & directory helpers:**
  - `_REFUSED_ROOTS`: `{"/", "/usr", "/bin", "/sbin", "/lib", "/lib64", "/etc", "/tmp", "/var", "/dev", "/proc", "/sys"}`.
  - `refuse_symlink(path: Path, label: str = "path", *, max_ancestors: int = 1) -> None`: walks `0..max_ancestors`, stops on filesystem root or `_REFUSED_ROOTS` (for `step > 0`), raises `ValueError(f"Refusing symlink {label}: {cur}")` at `step == 0` and `ValueError(f"Refusing symlink parent for {label}: {cur}")` at `step > 0` (preserving exact `"symlink parent"` wording tested by `tests/memory/test_marketplace.py:872`!).
  - `ensure_private_dir(path: Path, label: str = "directory", *, mode: int = 0o700, max_ancestors: int = 1) -> Path`: calls `refuse_symlink` BEFORE `path.mkdir(parents=True, exist_ok=True)` and `os.chmod(path, mode)`.
  - `atomic_write_text(path: Path, content: str, *, mode: int | None = 0o600, dir_mode: int | None = 0o700, refuse_ancestors: int = 1, label: str | None = None) -> Path`: calls `refuse_symlink`, creates `path.parent` (and `os.chmod(path.parent, dir_mode)` ONLY when `dir_mode is not None`), opens `tempfile.mkstemp(prefix=f".{path.name}.", suffix=".tmp", dir=path.parent)`, writes UTF-8 text, applies `mode` or umask-masked `0o666`, atomically calls `os.replace(tmp_path, path)`, and unlinks `tmp_path` (`missing_ok=True`) in `except`.

## 3. Policy Hardening Decomposition (`strands_code_cli/policy/core.py` & `scope.py`)

Keep every function well below `xenon C (20)` via small, pure helpers:
- `_has_shell_metachars(text: str, *, allow_quoted: bool = False) -> bool`:
  - When `allow_quoted=False` (`is_fetch_get`): rejects `;`, `|`, `&`, `` ` ``, `$(`, `\n`, `\r`, `>`, `<` anywhere in `text`.
  - When `allow_quoted=True` (shell `[[allow]]`): scans quotes/backslashes cleanly; rejects ANY `` ` `` or `$(` (even inside double quotes, since POSIX expands them), and rejects unquoted `;`, `|`, `&`, `\n`, `\r`, `>`, `<`.
- `_is_safe_curl_args(args: Sequence[str]) -> bool`: rejects `-F`, `-T`, `-d`, `-o`, `-O`, bundled/attached short flags containing `{F, T, d, o, O, I}`, `--form*`, `--json`, `--upload-file*`, `--output*`, `--remote-name*`, `--data*`, and `-X`/`--request` outside `GET`/`HEAD` (case-insensitive for HTTP method, case-sensitive for short flags!).
- `_match_path_rule(rule: Rule, tool_name: str, tool_input: dict[str, Any], base: Path, *, is_allow: bool) -> bool`:
  - Handles optional empty `raw` on `search` (`raw = tool_input.get("path") or "."` when `tool_name == "search"`).
  - For `is_allow=True`: canonical `realpath(abs)` + canonical repo-relative candidates ONLY.
  - For `is_allow=False`: BOTH raw/`normpath(abs)` AND canonical `realpath(abs)`/`relpath` candidates.
- `_match_command_rule(rule: Rule, tool_name: str, tool_input: dict[str, Any], *, is_allow: bool) -> bool`:
  - Normalizes command once. For `is_allow=True and tool_name == "shell"`: requires `not _has_shell_metachars(norm, allow_quoted=True)` and word boundary (`norm == rule.command` or `norm.startswith(rule.command) and norm[len(rule.command)].isspace()`). `python_repl` keeps prefix match cleanly.
- `_is_sensitive_read_path(raw: object, base: Path) -> bool` & `_is_protected_skills_or_config_path(raw: object, base: Path) -> bool`:
  - Expand write/edit protection to repo `.agent/**`, `.git/**`, any `.env`/`.env.*`, `STRANDS.md`, `~/.config/strands-code`, `~/.cache/strands-code`, `STRANDS_CODE_CACHE_DIR` (when set), `~/.config/strands-box`, `~/.local/share/strands-box`.
  - Sensitive read covers any `.env` / `.env.*`, `~/.ssh/**`, and `~/.aws/**` (matching both `normpath` and `realpath`).
- `effective_roots(cwd: str | Path, policy: Any, *, tool_name: str | None = None) -> list[Path]`:
  - Starts from deduplicated `[Path(os.path.realpath(cwd)), Path(os.path.realpath("/tmp"))]`; appends canonical `realpath` bases from `policy.allow` filtered to `tool_name is None or rule.tool in ("*", tool_name)`.

## 4. Direct Intervention Gate (`strands_code_cli/policy/policy_gate.py`)

```python
class PolicyGateHandler(InterventionHandler):
    """Single deterministic TOML+Python gate on Strands InterventionHandler."""

    @property
    def name(self) -> str:
        return "strands-code:policy-gate"

    # Keep default on_error = "throw" so TurnCancelled & KeyboardInterrupt propagate cleanly!
```

- **State encapsulated on handler instance (guarded by `threading.Lock`):**
  - `_mode: str` (`"act"` | `"plan"`)
  - `_main_agent_id: int | None`
  - `_agent_tags: dict[int, str]` (with `weakref.finalize` cleanup)
  - `_read_only_agents: set[int]` (`enter_read_only`, `exit_read_only`, `is_read_only`)
  - `_batch: BatchState` (with `threading.Lock`, SHA-256 of `json.dumps(tool_input, sort_keys=True, separators=(",", ":"), default=str)`)
  - `_broker: ApprovalBroker`
- **Classify & prompt order inside `async def before_tool_call(self, event, **kwargs)`:**
  1. `if getattr(event, "cancel_tool", False): return Proceed(reason="steering-redirected")`
  2. Read `tool_name`, sanitized `dict` `tool_input`, `agent = getattr(event, "agent", None)`, `tag = self.tag_for(agent)`.
  3. If `self.is_read_only(agent)` and `tool_name in PLAN_MUTATING_TOOLS` → `with RENDER_LOCK: print_plain(console, PLAN_DENY_TEMPLATE.format(tool=tool_name))` + `self._batch.record(...)` + return `Deny(reason=...)`.
  4. Load policy (`PolicyConfig` with repo `trust_delegated` ignored + warned).
  5. Evaluate `verdict = decide(tool_name, tool_input, policy)`.
  6. `Deny` → print `[denied ...]` (plus `REVISE_HINT` for `python_repl`) under `RENDER_LOCK` + record + return `Deny(reason=...)`.
  7. `Allow` → return `Proceed()`.
  8. `Prompt`:
     - `protected = _is_protected_prompt(tool_name, tool_input)`
     - If `policy.options.trust_delegated and self._main_bound and agent is not None and id(agent) != self._main_agent_id and not protected` → print auto-trust notice under `RENDER_LOCK` + return `Proceed(reason="delegated-trusted")`.
     - If `self._batch.is_covered(signature, tag=tag)` → return `Proceed(reason="batch-covered")`.
     - Otherwise invoke main-thread prompt & answer via `self._prompt_user(tag, tool_name, tool_input, verdict, signature, protected)` running header + `Syntax`/`Detail`/`Risk` + dialog/typed input INSIDE `broker.request(...)`!
  - Catch `(TurnCancelled, KeyboardInterrupt)` and `raise`; catch general `Exception` → log warning and return `Deny(reason="Approval gate failed closed — skipped, continuing.")`.
- **Attach gate directly to `agent`:** `agent._policy_gate = gate` in `build_agent` (`entry/main.py`) and read via `gate_for(agent)` helper in `loop/core.py` and `dispatch/core.py` (NO `_ACTIVE` module global!).

## 5. Custom Subagent & Clean Teardown (`strands_code_cli/entry/subagent.py`, `loop/btw.py`, `loop/core.py`)

- **Shared delegate tool-list isolator (`_fresh_tools_for_delegate`):**
  ```python
  def fresh_tools_for_delegate(tools: Sequence[Any] | None) -> list[Any] | None:
      if tools is None or not any(getattr(t, "tool_name", None) == "python_repl" for t in tools):
          return list(tools) if isinstance(tools, tuple) else None  # signals no copy needed when python_repl absent!
  ```
  - When `python_repl` is present, builds a new list substituting `SandboxedPythonInterpreter("", authorized_imports=set()).get_tool()` so `/btw` and `subagent` children never mutate the parent's `LocalPythonExecutor` state concurrently.
- **Custom `make_subagent` (`entry/subagent.py:build_cli_subagent`):**
  - Called from `entry/main.py:build_agent` with `builtin_tools["subagent"] = False` and a mutable `parent_holder = {"agent": None}` set right after `agent = create_harness(**kwargs)`.
  - Inside `builder(spec: AgentSpec)`: reads live `parent = parent_holder["agent"]`, sets `child_config["model"]` to `spec.model` OR `fresh_side_model(getattr(parent, "model", None))`, disables duplicate `caching=False` on `Model` instances, isolates `python_repl`, passes the shared `PolicyGateHandler` (registering `child` as `"subagent"` + propagating read-only if `gate.is_read_only(parent)`), applies `configure_streaming_for_model` / `configure_gemini_for_model` / `configure_openai_for_model` / `configure_base_url_for_model` + `register_memory_plugin(child, load_memory)`.
- **Guarded cancel & shutdown helpers (`loop/core.py`):**
  - `_cancel_agent_background_tasks(agent)`: calls `agent.cancel(cancel_background_tasks=True)` when callable.
  - `_shutdown_agent(agent)`: calls `agent.shutdown()` when callable; keep `flush_memory(agent)` at `:2451` right alongside it to satisfy `tests/memory/test_memory_file.py:245`.
