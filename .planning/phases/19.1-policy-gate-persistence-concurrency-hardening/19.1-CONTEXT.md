## Implementation Decisions

### Policy Gate & Core Classifier Hardening
- **D-01 (`PolicyGateHandler(InterventionHandler)` Migration & Per-Agent State):**
  - Replace `PolicyHumanInTheLoop(HumanInTheLoop)`, `DENY:` reason smuggling, `_ASK_TAG`, `_last_by_tag`, `SteeringState.arm`/`consume_arm`, and the `_ACTIVE` module global with a direct `PolicyGateHandler(InterventionHandler)` in `strands_code_cli/policy/policy_gate.py` (`strands.interventions.InterventionHandler`, returning `Proceed`, `Deny`, etc.).
  - Read `event.cancel_tool` directly inside `before_tool_call(self, event: BeforeToolCallEvent)` so steering-redirected tool calls short-circuit cleanly to `Proceed()` without `SteeringState.arm` / `consume_arm`.
  - Key agent identity by `id(agent)` (`"main"` for bound main agent, explicitly registered `"btw"` agent ids, and `"subagent"` for any other delegated agent — eliminating `btw`/`subagent` tag collision).
  - Support per-agent `read_only_agents: set[int]` alongside `ModeState` `"plan"` (`enter_read_only(agent)` / `exit_read_only(agent)` + propagating read-only posture onto delegated children).
  - Remove `allowed_tools=["read", "search"]` short-circuiting so all tool invocations classify through `decide()`; key `BatchState` signatures on `(agent_tag, tool_name, sha256(full_canonical_input))` instead of 200-char truncated strings.
  - Keep Python `interventions` 100% deterministic TOML + Python (never Cedar inside Python, never `"smart"`/NL-string policies). — *Reversibility: moderate — internal gate refactor preserving `build_interventions()`, `/policy`, and HITL transcript contracts.*

- **D-02 (`policy/core.py` & `policy/scope.py` P0/P1 Bypass Fixes):**
  - **`is_fetch_get()` (`policy/core.py:416-445`):** Reject shell metacharacters / chaining / redirections (`;`, `|`, `&&`, `||`, `&`, `` ` ``, `$(`, `\n`, `\r`, `>`, `<`), require normalized command to begin with `git fetch` (token-bounded) or `curl` (not arbitrary substring anywhere in a compound string), and reject curl upload/mutating/output-write flags (`-F`, `--form`, `--form-string`, `--json`, `-T`, `--upload-file`, `-d`, `--data*`, non-`GET`/`HEAD` `-X`/`--request`, `-o`, `--output`, `-O`, `--remote-name`).
  - **`_serialise_rule()` (`policy/core.py:324-331`):** Escape strings with TOML/JSON encoding (`json.dumps`), reject disallowed ASCII control characters (`< 32`, `\x7f`), and validate round-trip `tomllib.loads()` before `os.replace()`.
  - **Shell `[[allow]]` matching (`policy/core.py:409-412`):** Reject commands containing unquoted shell metacharacters (`;`, `|`, `&&`, `||`, `&`, `` ` ``, `$(`, `\n`, `\r`, `>`, `<`) against `[[allow]]` rules and enforce word-boundary matching (exact command match or prefix followed by whitespace); keep broad prefix/normalized matching on `[[deny]]` rules fail-closed.
  - **Symlink path matching (`policy/core.py:390-408`):** Match `[[allow]]` path rules against canonical `realpath` and canonical repo-relative paths **only** (never raw pre-symlink path strings); keep `[[deny]]` matching BOTH raw/normalized and canonical `realpath` candidates.
  - **`effective_roots(cwd, policy, *, tool_name=None)` (`policy/scope.py:78-98`):** Canonicalize default `cwd` and `/tmp` roots with `os.path.realpath()` and filter `policy.allow` rules by `tool_name` (`rule.tool in ("*", tool_name)`) when provided, ensuring `read` allow-rules cannot silently widen `write`/`edit` roots. — *Reversibility: easy — pure deterministic matching & scoping helpers.*

- **D-03 (Unboxed `read` Confinement & Sensitive-File Downgrade — Q1 & Q2):**
  - Once `read` classifies through `PolicyGateHandler` instead of `allowed_tools`:
    - In-scope `read` (resolving inside `effective_roots(cwd, policy, tool_name="read")`) remains silently `Allow()` unless matched by `[[deny]]` or a sensitive secret path.
    - Outside-scope `read` returns `Prompt` (`[y/n/always/never]`) naming the resolved path and allowed roots rather than hard-denying (`write`/`edit` outside `effective_roots` retain `Deny`; explicit `[[deny]]` on any tool retains `Deny`).
  - Expand `write`/`edit` protected-path `Prompt` downgrade (disabling `"Always — approve + remember rule"`) in `_is_protected_skills_or_config_path()` to cover:
    - Repo trees: `.agent/**` (adding `.agent/memory/`, `.agent/sessions/`, `.agent/session_index/` alongside `.agent/skills*`, `skills-lock.json`, `policy.toml`, `routing.yaml`, `MEMORY.md`), `.git/**`, `.env` & `.env.*` (at repo root or subdirs), and `STRANDS.md`.
    - Host dirs: `~/.config/strands-code`, `~/.cache/strands-code` (plus `STRANDS_CODE_CACHE_DIR` when set), `~/.config/strands-box`, and `~/.local/share/strands-box`.
  - ALSO apply protected-path `Prompt` downgrade (disabling `Always`) to `read` targeting sensitive secret files (`*/.env`, `*/.env.*`, `~/.ssh/**`, `~/.aws/**`, matching both normalized and `realpath` targets), establishing unboxed parity with Strands Box Dogwood's `forbid_sensitive_files_read` floor. — *Reversibility: easy — localized verdict & path table in `policy/core.py` and `_is_protected_prompt()`.*

- **D-04 (`trust_delegated` Hardening — Q3):**
  - Restrict `[options] trust_delegated` strictly to home policy (`~/.config/strands-code/policy.toml`): if repo `./.agent/policy.toml` sets `trust_delegated = true`, log a warning and ignore that option while keeping the rest of repo rules (including `[[deny]]`) active (`PolicyConfig.load()`).
  - Run `decide()` BEFORE applying `trust_delegated`: explicit `[[deny]]`, outside-scope `write`/`edit` denials, Plan/`read_only_agents` denials, and protected-write or sensitive-read `Prompt` verdicts ALWAYS override `trust_delegated`; only non-protected `Prompt` verdicts auto-approve (and announce) when `trust_delegated` is enabled by home config. — *Reversibility: easy — 1 loader check + classify ordering.*

- **D-05 (`KNOWN_TOOLS`, Live Harness Plugin Tools & Tool-Only Rules — Q4):**
  - Add all 4 live harness plugin tools registered by `create_harness` (`skills`, `search_memory`, `retrieve_context`, `strands_manage_background_task`) to BOTH `KNOWN_TOOLS` and `BUILTIN_ALLOWED_TOOLS` in `policy/core.py`, so they proceed smoothly in Plan/Act unless explicitly restricted via `[[deny]]` (while `subagent` spawn continues to prompt by default).
  - Support tool-only rules (`path = None`, `command = None`) across `_parse_rule`, `_validate_rule`, `match_rule`, `_serialise_rule`, and `_derive_rule` for non-file/non-command tools (`web_fetch`, `web_search`, `subagent`, `programmatic_tool_caller`, `skills`, `search_memory`, `retrieve_context`, `strands_manage_background_task`), and admit `search` in path-scoping rule validation/matching. — *Reversibility: easy — rule schema & validator extension.*

  - Fix Rich markup injection on launch banner (`loop/core.py:2526` → `print_plain(..., style="dim")`) and tighten `_validate_session_id()` (`entry/main.py:77-86`) to strict `[A-Za-z0-9][A-Za-z0-9._-]*` (rejecting `[`/`]` and matching `session_index.py:35`).
