## Security & Containment Threats (ASVS L1)

| ID | Threat | Mitigation in Plan 19.1-01 |
| :--- | :--- | :--- |
| `T-19.1-01` | `is_fetch_get()` shell-chain (`git fetch && rm -rf /`, `curl \| sh`) & curl `-T`/`-F`/`--json`/`-X POST`/`-o` upload/write bypasses (`-T`/`-X` case bug) | Reject metacharacters BEFORE `shlex.split`, enforce exact token-0 `git fetch` or `curl`, case-sensitive short-flag check via `_is_safe_curl_args` (`CC <= 10`) |
| `T-19.1-02` | `_serialise_rule()` raw string interpolation injecting `[[allow]]` or corrupting `policy.toml` (wiping `[[deny]]` rules) | JSON-escaped serialization + control-char guard + full `tomllib.loads` validation before atomic replace |
| `T-19.1-03` | Symlink traversal into `[[allow]]` globs (`allow` matches pre-`realpath`), shell prefix collision (`ls`→`lsof`), or cross-tool `read→write` root widening | `[[allow]]` matches canonical `realpath` only; shell `[[allow]]` requires no unquoted metachars + whitespace word boundary; `effective_roots` filters by `tool_name` + canonicalizes defaults |
| `T-19.1-04` | Unboxed `read` accessing outside-scope paths or sensitive secret files (`.env`, `.env.*`, `~/.ssh/*`, `~/.aws/*`) silently | `decide()` checks `read` outside `effective_roots(..., tool_name="read")` → `Prompt`; sensitive secret reads → `Prompt` (Always disabled in `19.1-02`); `write`/`edit` protected paths cover `.agent/**`, `.git/**`, `.env*`, `STRANDS.md`, host config/cache/box |
| `T-19.1-05` | Untrusted cloned repo `./.agent/policy.toml` setting `[options] trust_delegated = true` to auto-approve subagent/btw tool calls | `PolicyConfig.load()` restricts `trust_delegated` strictly to home policy and logs warning when repo sets it (preserving repo `[[deny]]`/`[[allow]]`) |
| `T-19.1-06` | Symlink / temp-file clobber or world-readable `0o644` leak on private config/session files vs accidental `0o600` on git-tracked files | `platform_io.atomic_write_text` checks target + ancestors via `refuse_symlink`, writes `mkstemp(..., dir=parent)` + `0o600` private / `/proc/self/status` umask-masked standard readable for `mode=None` (no global `os.umask()` mutation) |
</threat_model>
