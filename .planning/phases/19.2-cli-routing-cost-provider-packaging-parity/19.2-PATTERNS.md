## Pattern 1: Canonical `provider_of()` Leaf & Mantle Box Egress (`D-06`, `D-08`)

Create `strands_code_cli/model/provider_id.py` (stdlib only — zero internal imports):

```python
def provider_of(model: str, *, unwrap_litellm: bool = False) -> str:
    """Canonical provider owning ``model`` (``bedrock`` for ARNs and bare ids).

    Args:
        model: Model identifier or reference.
        unwrap_litellm: When True, unwrap ``litellm/openrouter/...`` ->
            ``"openrouter"`` and ``litellm/ollama*/...`` -> ``"ollama"``
            for credential preflight, base_url scoping, and Box egress.
            When False (default), preserve ``"litellm"`` so ``_MEDIA_LESS``
            and capability overrides match uniformly.
    """
    cleaned = model.strip() if isinstance(model, str) else ""
    if not cleaned or cleaned.startswith("arn:") or "/" not in cleaned:
        return "bedrock"
    prefix, _, rest = cleaned.partition("/")
    low = prefix.lower()
    if unwrap_litellm and low == "litellm":
        sub = rest.partition("/")[0].lower()
        if sub in ("ollama", "ollama_chat"):
            return "ollama"
        if sub == "openrouter":
            return "openrouter"
    return low
```

- Wire `entry/first_run.py` (`_provider_of(m) = provider_of(m, unwrap_litellm=True)`), `entry/provider_config.py` (`_provider_of_model(m) = provider_of(m, unwrap_litellm=True)` + `scoped_base_url` consistency), `model/model_switch.py` (`_provider_of(m) = provider_of(m)`), and `sandbox/box.py` (`_provider_from_model_id` checks `normalize_model_ref` + `provider_of(ref, unwrap_litellm=True)` filtered to egress-bearing providers including `"bedrock-mantle"`).
- Add `"bedrock-mantle"` to `box.py:CORE_PROVIDERS` with host pattern `bedrock-mantle.{region}.api.aws` and bearer/IAM spec so Box users targeting Mantle models get accurate egress rules.

## Pattern 3: Session-Sticky Toggles + Consolidated `config.yaml` + Per-Session `PendingStore` (`D-01`, `D-02`)

1. **`ProviderConfig` (`entry/provider_config.py`)**:
   - `_KNOWN_KEYS = {"model", "base_url", "api_mode", "codeact", "diff_mode", "memory_mode"}`
   - Validate `diff_mode` against `("on-demand", "auto")` and `memory_mode` against `("curate", "silent")`; `codeact` against `CodeactState.VALID`.
   - Retire `codeact_remember` and `save_codeact_choice()`; remove `policy/diff_config.py` and `MemoryModeConfig` (`memory/memory_modes.py`).
2. **`DiffModeState` (`policy/diff_gate.py`)**:
   - Mirrors `ModeState` / `MemoryModeState` / `CodeactState`: `VALID = ("on-demand", "auto")`, `DEFAULT_MODE = "on-demand"`, `.mode`, `.set(mode)`, `.announce()`.
   - `run_loop` initializes `mode = ModeState()`, `diff_mode = DiffModeState(initial=cfg.diff_mode or "on-demand")`, `memory_mode = MemoryModeState(initial=cfg.memory_mode or "curate")`, `interface = CodeactState(initial=codeact or cfg.codeact or "tool")` — loaded ONCE from `ProviderConfig.load()`, never written back on slash commands.
3. **Per-`session_id` `PendingStore`**:
   - `PendingStore(root, session_id=session_id)` resolves `pending-{session_id}.json` when `session_id` is given (refusing path separators / invalid session ids) and falls back to `pending.json` when omitted for standalone store instantiation.
   - `entry/main.py:build_agent` binds `store = PendingStore(session_path, session_id=session_id)` and keeps a thin helper `_build_diff_tools(cwd, store, diff_mode_ref)` or keeps `get_mode` wired from `run_loop` / holder callback without adding branches to `build_agent` (`CC = 20`!).
   - Important wiring detail: since `DiffModeState` lives in `run_loop` while `make_gated_write`/`make_gated_edit` are constructed in `build_agent` (or read state at tool call time), attach a tiny callable slot on `agent` (e.g., `diff_mode_ref = {"mode": initial_diff_mode}` stashed as `agent._diff_mode_ref` or `DiffModeState` passed/bound like `gate.set_mode`), so `/diff on-demand` vs `/diff auto` flips live inside the running session AND `PendingStore` responds immediately without extra `build_agent` branches!

## Pattern 4: Safe Bounded `unified_diff` Preview (`D-02`)

1. **`policy/policy_gate.py` (`_render_prompt_header` helper `_render_diff_preview`)**:
   - Constants: `_MAX_DIFF_PREVIEW_LINES = 40`, `_MAX_DISK_PREVIEW_BYTES = 256 * 1024`.
   - For `edit`: extract `path`, `old_str`, `new_str`; if `old_str` & `new_str` are strings, call `preview_for_edit(path, old_str, new_str)`. Zero disk reads.
   - For `write`: extract `path`, `content`; only read existing file on disk via a guarded helper `_safe_existing_text_for_preview(path, cwd)` that:
     1. Resolves + confines `path` against `(cwd, Path("/tmp"), *effective_roots(cwd, policy, tool_name="write"))` and checks `refuse_symlink_under_roots` (`ValueError` -> omit existing read, show note).
     2. Checks `not _is_sensitive_read_path(str(confined), cwd)` and `not _is_protected_skills_or_config_path(...)` (if sensitive -> omit existing read, show safe creation/content preview note).
     3. Calls `os.lstat` -> must be regular file (`stat.S_ISREG`), not symlink (`not stat.S_ISLNK`), size `<= _MAX_DISK_PREVIEW_BYTES`, strict UTF-8 decode (`errors="strict"` -> fallback note on binary).
     4. If file does not exist (`FileNotFoundError`) -> `old_text = ""` (clean `+` diff).
   - Truncate diff lines to `_MAX_DIFF_PREVIEW_LINES` (`... (+N more lines)`), sanitize with `sanitize_multiline`, and render via `console.print(Syntax(snippet, "diff"))` under `RENDER_LOCK`.
2. **`dispatch/core.py` (`/diff show [path]`)**:
   - Normalize `verb = rest.strip().lower().partition(" ")[0]` so `/diff SHOW` and `/diff show foo.py` both work.
   - Bare `/diff`: compact summary list (`Diff mode: <mode> (<N> pending).` + per-file `op: path`).
   - `/diff show [path]`: renders `unified_diff(entry["old_text"] or "", entry["new_text"], path)` (sanitized via `sanitize_multiline`) for matching pending file(s).

## Pattern 5: Shared Session Prefix Resolution & Strict `/skills` Arg Parsing (`D-03`)

- **Shared prefix helper** (in `dispatch/core.py` or `session/session_index.py`):
  `resolve_session_prefix(known: set[str], target: str, *, usage_hint: str) -> tuple[str | None, str | None]`
  - Exact match in `known` -> `(target, None)`.
  - Unique prefix `[sid for sid in known if sid.startswith(target)]`:
    - `len == 1` -> `(matches[0], None)`
    - `len > 1` -> `(None, f"Ambiguous session prefix {target!r} — matches ...")`
    - `len == 0` -> `(None, None)` (caller decides: `/forget` & `/resume` return unknown-session reply; `--session-id` treats `checked` as a new explicit session id and calls `index.ensure(checked)`!).
- **Strict `/skills` `_parse_flag_args(raw, *, flags_with_values=frozenset(), allowed_switches=frozenset())`**:
  - Reject any `--flag` token not in `flags_with_values | allowed_switches` with `ValueError(f"Unknown flag {tok}")` (also reject `--flag=val` cleanly or split and check name before `=`).

## Pattern 7: Unified OpenAI & `bedrock-mantle/openai.*` Effort Table (`D-07`)

def _openai_family_tail(normalized: str) -> str | None:
    """Return lowercase OpenAI model tail for openai/ and bedrock-mantle/openai.*, else None."""
    prov = provider_of(normalized)
    tail = _base_key(normalized).lower()
    if prov == "openai":
        return tail
    if prov == "bedrock-mantle" and tail.startswith("openai."):
        return tail[len("openai.") :]
    return None
