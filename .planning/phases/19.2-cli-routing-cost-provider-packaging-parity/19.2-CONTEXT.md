- **D-01 (Unified Session-Sticky Toggles & `config.yaml` Startup Defaults — R1-Q1, R1-Q2, R2-Q1):**
  - All 5 session toggles (`/mode`, `/route on|off`, `/memory mode` restoring Phase 6 `D-07`, `/codeact`, and `/diff on-demand|auto`) are **session-sticky in memory only** — slash switches never write back to disk.
  - Consolidate startup defaults into `~/.config/strands-code/config.yaml` (`ProviderConfig` in `strands_code_cli/entry/provider_config.py`) with uniform direct keys: `model`, `base_url`, `api_mode`, `codeact` (`tool|code|both`), `diff_mode` (`on-demand|auto`), and `memory_mode` (`curate|silent`). Retire `codeact_remember` so `codeact`, `diff_mode`, and `memory_mode` behave uniformly as direct startup defaults.
  - **Clean break on legacy files:** Retire `diff.yaml` (`strands_code_cli/policy/diff_config.py`) and `memory.yaml` (`MemoryModeConfig` in `strands_code_cli/memory/memory_modes.py`); ignore any leftover legacy files on disk rather than carrying migration or fallback loaders. — *Reversibility: moderate — schema consolidation across entry, dispatch, policy, and memory.*

- **D-02 (`/diff` Cleanup, Per-`session_id` `PendingStore` & `unified_diff` Previews — R1-Q3):**
  - Retire dead `/diff approve-each` mode and `_default_ask` (`strands_code_cli/policy/diff_gate.py`) — `PolicyGateHandler` owns pre-write approval (`gate_active=True`); valid `/diff` modes are `on-demand` (default) and `auto`.
  - Fix `/diff SHOW` case-insensitivity (`dispatch/core.py`) and scope `PendingStore` strictly per `session_id` (e.g., `pending-<session_id>.json` or session-scoped directory inside `session_path`, never one shared `pending.json` across sessions).
  - Render `unified_diff` previews in **both** places:
    1. HITL `write`/`edit` approval prompts (`PolicyGateHandler._render_prompt_header` in `strands_code_cli/policy/policy_gate.py`) — bounded to ~40 lines with a truncation note, sanitized via `sanitize_multiline`, matching `python_repl` `Syntax` preview parity.
    2. `/diff show [path]` (`dispatch/core.py`) — shows unified diffs for stashed changes (while bare `/diff` stays a compact file summary list). — *Reversibility: easy — localized diff store, dispatch formatting, and HITL header rendering.*

- **D-03 (CLI Flag, Session Prefix Resolution, `/skills` & Alias Cleanup — R1-Q4):**
  - Retire `_expand_bare_codeact` `sys.argv` rewriting (`strands_code_cli/entry/main.py`); `--codeact` becomes an explicit enum option (`--codeact tool|code|both`) validated cleanly by Typer/Click so bare `--codeact` errors cleanly listing allowed values.
  - Add unique prefix resolution parity (matching `_resolve_forget_target`) to both `/resume <prefix>` (`dispatch/core.py`) and `--session-id <prefix>` (`entry/main.py`: exact match wins, unique prefix resolves to full existing session id, ambiguous prefix fails loudly listing matches, and non-matching explicit `--session-id <new-id>` still creates a new session).
  - Prune redundant aliases (`/models`, `/skill`, `/skills refresh`, `/skills uninstall`) from dispatch, completer, and `USAGE_HINT`; fix `/skills` bare `marketplace`, bare `show`, bare `remove`, and strict unknown `--flag` rejection (`_parse_flag_args`). — *Reversibility: easy — CLI parsing, session resolution, and slash dispatch cleanup.*
