## Security & Reliability Threats (ASVS L1)

| ID | Threat | Mitigation in Plan 21-03 |
| :--- | :--- | :--- |
| `T-21-08` | Git CLI option injection or command injection via crafted `<base-ref>` (e.g. `--output=/tmp/pwn`, `-c core.fsmonitor=...`, `; rm`, control chars) | Strict `parse_review_args` + `validate_base_ref` rejecting leading `-`, whitespace, control chars, NUL, and range abuse; verify via `git rev-parse --verify --end-of-options <ref>^{commit}` and always pass `--end-of-options` / `shell=False` with timeout (`D-09`) |
| `T-21-09` | Prompt injection inside uncommitted/PR git diffs causing mutating tool calls, spurious `@file` host reads, or exfiltration into external `/route` decision models | Frame diff + `--stat` inside `<untrusted_git_diff>` data-only prompt (`256 KiB` cap), disable `@file` token expansion on `/review` turns, send ONLY sanitized command/focus string (`routing_ask`) to `_route_pre_turn`, and run under `PolicyGateHandler.enter_read_only(agent)` (`D-10`, `D-11`) |
| `T-21-10` | Sticky `ModeState` (`act`/`plan` + `pending_plan`) or `CodeactState` (`code`/`both`) / `CodeactStint` left corrupted after `/review` error or `KeyboardInterrupt` | Always pair `enter_read_only(agent)` with `exit_read_only(agent)` in `finally:`; force `turn_interface = "tool"` locally without touching `interface` holder; skip `note_plan_proposed()` on review turns (`D-11`) |
</threat_model>
