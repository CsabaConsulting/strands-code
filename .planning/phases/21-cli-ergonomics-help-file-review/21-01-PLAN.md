# Plan 21-01: Tracer — `/help` Declarative Registry, 3-Site `RejectCallerToolUseHook` & `"document"` Model-Switch Conversion

<objective>
Establish the Wave 1 foundation for Phase 21 (`LOOP-06`, `TOOL-05`):
1. Build `strands_code_cli/dispatch/help.py` (`D-01`, `D-02`) as the single declarative command registry driving both `/help` / `/help <name>` (built-ins + loaded skills + warnings) and `USAGE_HINT` in `dispatch/core.py`, adding `"help"`, `"file"`, and `"review"` to `BUILTIN_SLASH_HEADS` (`memory/skills.py`).
2. Build `strands_code_cli/policy/tool_use_guard.py` (`D-06`, `D-08`) implementing `validate_content_blocks()` (strictly allowlisted `"text"`/`"image"`/`"document"` dicts) and fail-closed `RejectCallerToolUseHook` (`BeforeInvocationEvent.cancel` at `HookOrder.SDK_FIRST`) wired across all 3 CLI agent sites (`entry/main.py`, `loop/btw.py`, `entry/subagent.py`).
3. Extend `strands_code_cli/model/model_switch.py` and `strands_code_cli/cost/cost_context.py` (`D-07`) so `"document"` blocks convert safely across media-capable and media-less models (and roundtrip cleanly through `RichHistory` / `canonical_prefix_hash` / `estimate_messages_tokens`).

Purpose: Land `/help` end-to-end as the Wave 1 tracer and put the CVE-2026-18830 guard + `"document"` conversion infrastructure in place before Wave 2 (`21-02`) ships `@file` / `/file` attachments.
</objective>

## Security & Reliability Threats (ASVS L1)

| ID | Threat | Mitigation in Plan 21-01 |
| :--- | :--- | :--- |
| `T-21-01` | CVE-2026-18830 / CoreBreak: caller-supplied `"toolUse"` block executed directly by `event_loop_cycle` without model mediation across main, `/btw`, or `subagent` agents | Register fail-closed `RejectCallerToolUseHook` (`BeforeInvocationEvent` at `HookOrder.SDK_FIRST`) across `entry/main.py`, `loop/btw.py`, and `entry/subagent.py` (`D-08`) + strict allowlisted `validate_content_blocks()` rejecting anything outside `text`/`image`/`document` |
| `T-21-02` | `"document"` blocks crash media-less models after `/model` switch, leak bytes into `_block_chars`, or break `RichHistory` prefix hashes | Extend `_MEDIA_PLACEHOLDER_RE`, `_canonical_block`, `_media_placeholder_block`, and `_convert_block` in `model_switch.py` for `"document"` parity (`D-07`), and guard `_block_chars` in `cost_context.py` |
| `T-21-03` | ANSI/control/Bidi injection in skill metadata printed via `/help` or drift between `BUILTIN_SLASH_HEADS`, `USAGE_HINT`, and `/help` | Derive `USAGE_HINT` programmatically from `dispatch/help.py` (`D-01`), pass all rendered strings through `sanitize_display()` / `print_plain`, and test 1:1 registry parity |
</threat_model>
