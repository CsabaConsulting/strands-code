<threat_model>
## Security & Supply-Chain Threats (ASVS L1)

| ID | Threat | Mitigation Across Phase 18 Plans |
| :--- | :--- | :--- |
| `T-18-01` | Ambient `GITHUB_TOKEN` / `GH_TOKEN` leaking into offline tests, logs, disk, or non-GitHub hosts | Add both to `tests/conftest.py:_PROVIDER_ENV_VARS`; read strictly via `read_github_token()` inside `memory/marketplace.py` (trimmed, control-char rejected), sent ONLY to `api.github.com`, never persisted to `marketplaces.yaml` / `skills-lock.json` / error strings |
| `T-18-02` | Tarball / local-catalog symlink exfiltration (`references/leak.md -> ~/.aws/credentials`), hardlinks, FIFOs, devices, `.gitmodules`, or `..` zip-slip traversal | Reject every non-regular/non-dir tar member, non-empty `linkname`, `\x00`, absolute path, `..`, and `.gitmodules` in `extract_tarball_subdir_safe()` & `copy_local_dir_safe()`; refuse symlinks at every parent/skill level in `verify_installed_marketplace_skills()` |
| `T-18-03` | Compressed tarball bomb or huge repository DoS | Enforce `MAX_TARBALL_BYTES = 25 MiB` (pre-read `Content-Length` + stream byte cap) and per-skill unpack caps (`MAX_SKILL_FILES = 256`, `MAX_SKILL_BYTES = 5 MiB`) |
| `T-18-04` | Branch/tag mutation drift or silent on-disk tampering of installed marketplace skills | Pin immutable 40-char hex `commit_sha` + deterministic SHA-256 `computed_hash` in `./.agent/skills-lock.json`; `verify_installed_marketplace_skills()` fail-closed warn-and-skips missing/drifted/symlinked skills until `/skills sync` |
| `T-18-05` | Remote `allowed-tools` escalation & bundled `scripts/*` execution risk | Keep `allowed-tools` strictly informational in `/skills show`; detect and prominently warn on bundled `scripts/*` during install/update (and diff added/changed scripts on update), never auto-executing |
| `T-18-06` | Broad repo `[[allow]]` globs (`path = "*"`, `.agent/**`) silently overwriting `.agent/skills*`, `.agent/skills-lock.json`, or `~/.config/strands-code/**` | Implemented in `18-02-T1`: `_is_protected_skills_or_config_path()` in `policy/core.py:decide()` downgrades matched `Allow()` verdicts to `Prompt(...)` via canonical `realpath` checks |
| `T-18-07` | ANSI escape / Rich `[...]` markup injection in third-party skill metadata or errors | `sanitize_display()` strips ASCII control chars (`< 0x20`, `0x7f`) on metadata/warnings; outputs render strictly through `print_plain(markup=False)`; remote invocations carry explicit `@ <short_sha>` provenance framing (`18-02-T2`) |
| `T-18-08` | HTTP redirect SSRF or token forwarding during tarball download | `make_marketplace_client()` uses `follow_redirects=False` and allows at most one redirect strictly to `https://codeload.github.com/...` or `https://objects.githubusercontent.com/...` without forwarding `Authorization` |
</threat_model>
