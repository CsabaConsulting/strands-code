## v1 Requirements

### Task Loop

- [x] **LOOP-01**: User can hold a multi-ask conversation where the CLI plans and executes each ask with subagents and tools — *Validated Phase 1*
- [x] **LOOP-02**: User can steer a running task with freeform input applied at the next tool-call boundary — *Validated Phase 4*
- [x] **LOOP-03**: User can ask a side question mid-task via a `/btw`-style escape answered by a subagent without disturbing the main task — *Validated Phase 7*
- [x] **LOOP-04**: User can cancel a running task with Ctrl-C without quitting the CLI — *Validated Phase 4*

### Modes

- [x] **MODE-01**: User can work in Plan mode (read-only, presents a plan) and approve before Act executes — *Validated Phase 4*
- [x] **MODE-02**: User can cycle modes without restarting the session — *Validated Phase 4*

### Tools & Safety

- [x] **TOOL-01**: Agent can read, write, and edit files and run shell commands as first-class tools — *Validated Phase 2*
- [x] **TOOL-02**: User can review pending changes in a `/diff` viewer before they apply — *Validated Phase 2*
- [x] **TOOL-03**: User is prompted for approval before edits, shell, and network actions per a deny-first policy file — *Validated Phase 3*
- [x] **TOOL-04**: Agent navigates repos with agentic grep/READ without an index to maintain — *Validated Phase 2*
- [x] **TOOL-07**: User can opt into code-generation-first (CodeAct) actions reconciled with deny-first approvals; tool-calling stays the default and CodeAct is never mandatory — *Validated Phase 11 (Complete)*

### Session & Context

- [x] **SES-01**: User can resume a session by UUID across runs (`--session-id`, `/resume`) — *Validated Phase 1*
- [x] **SES-02**: User can compact, clear, and inspect context usage (`/compact`, `/clear`, `/context`) — *Validated Phase 5*
- [x] **SES-03**: Sessions flush on exit so resume never silently loses work — *Validated Phase 1*

### Models & Cost

- [x] **MODEL-01**: User can switch providers mid-session via `/model` (Bedrock default, override-friendly) — *Validated Phase 5*
- [x] **MODEL-02**: User can see cost and token usage per session and task via `/cost` (display only, no enforcement) — *Validated Phase 5*
- [x] **MODEL-03**: CLI auto-selects model and thinking budget per ask via a decision model (Jev/Kev/Laya class), with manual override — *Validated Phase 8*
- [x] **MODEL-04**: CLI can route decisions through Jev via TypeSafe's native API (`TYPESAFE_API_KEY`), alongside OpenRouter and Ollama engines — *Validated Phase 9*
- [x] **MODEL-05**: `/cost` shows provider-reported actuals for main turns where supplied (OpenRouter), estimates elsewhere, without double counting — *Validated Phase 10 (Complete)*

### Skills & Memory

- [x] **SKILL-01**: CLI loads skills from local `./.agent/skills` and the user can list and invoke them — *Validated Phase 6*
- [x] **SKILL-02**: CLI auto-loads the repo memory file and the user can scaffold and edit it (`/init`, `/memory`) — *Validated Phase 6*

## v2 Requirements

### GitHub (no dedicated loop phase: Claude Code has none either — `gh` flows ride on general tool competence, verifiable today)

- **GITHUB-01**: (covered, no build) User can drive read-issue → branch → implement → test → open-PR from a single ask via shell tool + `gh`
- **GITHUB-02**: (covered, no build) User can create issues, comment on reviews, and check CI status from the CLI via shell tool + `gh`
- **REVIEW-01**: User can request a code review of pending changes via a small future `/review` slash

### Extensibility

- **SKILL-03**: User can add marketplaces and install skills from them (after local skills proven)
- **SKILL-04**: CLI consumes MCP servers as tools via user config (on first integration request)

### Automation

- **LOOP-05**: User can run the CLI non-interactively with JSON output for CI and scripts (on first CI user)

### Memory

- **SKILL-05**: No Hindsight integration ships in the repo; heavy recall backends are explicitly out of scope (Hindsight's Postgres + background loop too heavy for a coding harness; OpenViking's AGPL server rejected) — Strands native memory stays the only backend

### Interaction

- **TOOL-05**: User can attach files and symbols with an `@`-triggered picker (typing filters, up/down navigates, tab selects); start simple, sophistication only if a later phase calls for it
- **TOOL-06**: User can export trimmed session content to a text file via `/copy` (trailing whitespace stripped, optional back-scroll limit)
- **MODE-03**: User can pick fast/thorough effort presets layered over Plan/Act (on demand)
- **REVIEW-02**: User can run review flows with modes, locally and in CI through the headless runner

### Structure & Hygiene

- **STRUCT-01**: Codebase passes a measurement-first structural review: complexity and coupling measured, oversized modules broken up, CLI organized into packages, rig split into per-area files — full suite and rig green throughout
- **CLEANUP-01**: Repo contains no dead example code; README references only shipped surfaces (examples/pdf_to_okf_bundle removed)

### Ecosystem Alignment (Explored 2026-11-20 — see `.planning/research/V2-ALIGNMENT.md`)

- **UPSTREAM-01**: Resync onto `strands-agents >=1.65` and `strands-harness >=0.4`, retiring upstream-fixed shims (`#5166` restore reasoning strip, `#5158` `ContextInjector` adjacency) and migrating `strands_code_cli/routing/` transports onto `strands.decisions.DecisionModel` while keeping calibrated `0.62`/`0.04` gating and `/route` UX
- **MODEL-06**: First-class `google/` Gemini provider support (`gemini` extra, provider-aware startup preflight replacing `Bedrock-or-stop`, `google/` reasoning/effort via `_harness_supports_thinking`, `/model` discovery, `/cost` coverage, and AI Studio + Google AI Ultra monthly credit setup docs)
- **SANDBOX-01**: Run `strands-code` inside Strands Box on Linux (`box.toml` + deterministic Dogwood `policy.dw` + out-of-band credential egress proxy) as an OS-enforced floor beneath HITL approvals
- **EVAL-01**: Automated trajectory and prompt-injection red-team evaluation suite built on `strands-agents-evals` (`TrajectoryEvaluator`, `ActorSimulator`) complementing `scripts/uattest/`
- **LOOP-06**: Explicit `/help` command listing built-in slash commands and loaded local skills

## Out of Scope

| Feature | Reason |
|---------|--------|
| Persistent semantic code index | A project of its own; grep-first suffices for v1, index gets its own later phase |
| Enforced token budgets | Display builds trust; halting mid-task is a policy decision for later |
| Fully automatic model routing with no override | Opacity violates the manual-control constraint; Phase 8 keeps manual switching + explicit override, routing proposes but never silently decides |
| AgentCore as required path | Couples the CLI to AWS control plane; breaks the offline default (AWS-optional constraint) |
| IDE extension / browser companion | Separate product surface; terminal picker covers the need |
| Auto-commit / auto-push | Silent mutation of shared history conflicts with deny-first posture |
| Real-time multi-user collaboration | Session identity and presence are a second product; one actor per session |
| Custom vector DB / bespoke memory | Duplicates tested upstream `MemoryManager` defaults; tiered adapters instead |
| Consumer OAuth piggybacking on Gemini CLI / Code Assist | Violates Google ToS; personal Google AI Pro/Ultra plans already include monthly Google Developer Program credits ($10–$100/mo) usable legally via a standard AI Studio API key |
