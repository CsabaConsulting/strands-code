# Research Summary — Strands Code v2.0

**Completed:** 2026-11-21
**Milestone:** `v2.0` (Ecosystem Alignment, Google Gemini, Skills Marketplaces, Strands Box Linux, UX & Strands Evals)

---

## Executive Summary

Across four parallel domain investigations covering **`strands-py` (`v1.65+`) & `harness-py` (`v0.4.0+`)**, **Skills Marketplaces (`SKILL-03`)**, **Strands Box on Linux (`SANDBOX-01`)**, and **Strands Evals + CLI UX (`EVAL-01`, `LOOP-06`, `TOOL-05`, `REVIEW-01`)**, we confirmed a cohesive 7-phase `v2.0` architecture that converges onto upstream Strands primitives while preserving every differentiator `strands-code` built in `v1.0`:

1. **Upstream Resync First (Phase 13):** Locking `strands-agents >=1.65` and `strands-harness >=0.4.0` eliminates the longest-running v1.0 blocker (`#5166` cross-family `reasoningContent` restoration crash), fixes OpenAI/OpenRouter `ContextInjector` tool-result adjacency (`#5158`), adds Nova 2 & Haiku 5.5 thinking (`#4853`/`#5159`), exposes `Model.model_info`, and surfaces two important upstream shifts to handle immediately: `ContextInjector`'s persisted `InjectedBlock` format in token/hash estimation and removal of the unallowlisted default `"todos"` plugin. We intentionally **keep** `BeforeToolCallEvent.cancel_tool` for mid-turn steering (`Agent.cancel()` aborts whole turns) and **enable** `streaming=False` for `_NO_STREAMING_TOOLS` (Bedrock Llama 3/4).
2. **Google Gemini & Personal Google AI Ultra Solved Without Consumer OAuth Hacks (Phase 14):** Personal **Google AI Ultra** plans (\$40–\$100/mo Developer Program credits) work natively and legally through a standard **Google AI Studio API key** once billing/credits are claimed in `aistudio.google.com`. Research uncovered three latent CLI bugs before Gemini can run reliably: un-stripped `toolUse["reasoningSignature"]` corrupting `LiteLLMModel` tool IDs on model switches, `_vendor_family()` splitting `gemini-2.5-pro` on its version dot, and `litellm_entry()` missing `gemini/<tail>`. Replacing `first_run.py`'s unconditional Bedrock STS check with a provider-aware non-empty env preflight unblocks both Google-only users and headless Strands Box launches at the same time.
3. **Selective Convergence on `strands.decisions.DecisionModel` (Phase 15):** Python `strands-py` ships all 5 `DecisionModel` classes (`TypeSafeDecisionModel`, `DecisionsAPIDecisionModel`, `LLMDecisionModel`, `SageMakerDecisionModel`, `DecisionModel`), making it clean to replace custom TypeSafe HTTP boilerplate while keeping `OpenRouterDecisionModel` (for `64 KiB` caps & inline USD `cost`), `OllamaDecisionModel`, and our pre-turn `apply_model_action` + `0.62`/`0.04` gate + two-call effort pipeline (instead of `ModelRouter`).
4. **Deny-First Remote Skills Marketplaces (Phase 16):** Since neither `harness-py` nor `find_integrations` ships an `AgentSkills` marketplace installer, keeping `./.agent/skills` pure for `local:` and installing marketplace skills into `./.agent/skills-marketplaces/<ns>/<skill>` tracked by immutable SHA/hash entries in `./.agent/skills-lock.json` satisfies SDK naming invariants while preventing symlink exfiltration, zip-slip, and `allowed-tools` privilege escalation.
5. **Strands Box Linux Integration (Phase 17):** Strands Box (`v0.2.3+`) is now ready on Linux via a 3-binary Rust wrapper (`CLONE_NEWUSER`/`NET`/mount namespaces + `seccomp-bpf`, not `bwrap`/Landlock), Dogwood `.dw` temporal policies (scoped `D-05` revisit), and an out-of-band credential proxy compatible with all 5 `strands-code` providers when `first_run.py` avoids prefix checks / STS calls under `STRANDS_BOX=1` and `codeact_shell` routes via `sh -c`.
6. **Dedicated UX & Modularity Guardrails (Phase 18) Followed by Strands Evals (Phase 19):** Placing `/help`, `@file`/`/file`, and Python-diff-collected read-only `/review` in dedicated modules keeps `run_loop` (`C 18`) and `_setup_decision_entries` (`C 20`) safely inside `xenon`'s `C` budget, after which `strands-agents-evals >=1.10` (`scripts/evals/` + `tests/evals/`) provides offline trajectory invariants in CI plus live `ActorSimulator` and Crescendo/GOAT/PAIR red-teaming across skills, memory, routing, and CodeAct.
